# Portfolio

Static one-page portfolio (plain HTML/CSS/JS, no build step) for GitHub Pages.

## Edit
- Content: `index.html`. Replace the placeholder links in the Contact section (search for `TODO`).
- Styles and colours: `style.css` (tokens at the top).

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this folder.

## Deploy
1. Create a public repo on GitHub named `<username>.github.io`.
2. Push this folder to its `main` branch.
3. Repo Settings → Pages → Source: "Deploy from a branch", `main` / `(root)`.
